### About Me

- 🔭 **What I'm building:**
  - **[Dictatly](https://github.com/21dkkk/Dictatly)** — Fast, private speech-to-text dictation client for Windows. Powered by local Whisper models (`faster-whisper`), a floating caret HUD widget, and SQLite history.
  - **[NextSet](https://t.me/nextset_app)** — Clean, offline-first progressive web app for logging gym workouts with local IndexedDB storage.
- 🌱 **What I'm learning right now:**
  - Systems programming in Python and C++, Win32 APIs, and audio stream buffering.
  - Modern React patterns, state management, and offline storage resilience.
- 💬 **Ask me about:** Python desktop apps, PySide6/Qt, client-side persistence, or running Whisper models locally on your GPU.
- ⚡ **Outside of code:** Gym & strength training, mechanical keyboards, and tech podcasts.
